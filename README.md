Dashboard em Power BI para análise da cubagem de produtos no recebimento, com dados de planilhas Excel. O projeto reúne indicadores de acuracidade, registros corretos, divergências, dados incompletos e produtos sem cadastro, além de gráficos por setor e filtros interativos.

Com Power Query e medidas DAX, o painel facilita a identificação de inconsistências e apoia a priorização das correções cadastrais, oferecendo uma visão clara das informações utilizadas na operação logística.

**Tecnologias:** Power BI, Power Query, DAX e Excel.
